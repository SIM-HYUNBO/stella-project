# WAGIE 운영 설정

- 공지 발송에는 Firebase Auth의 `admin: true` 커스텀 클레임 또는 서버 환경 변수 `ADMIN_UIDS`에 등록된 Firebase UID가 필요하다. `ADMIN_UIDS`는 쉼표로 구분한다. 닉네임으로 권한을 부여하지 않는다.
- 배지 집계에 필요한 쿼리 인덱스는 `firestore.indexes.json`에 있다. 운영 Firebase에 기존 인덱스를 유지하면서 추가한다. 인덱스가 생성되기 전에는 읽지 않은 개수를 기존 방식으로 계산한다.
- 새 가입 흐름은 `nicknameClaims`와 사용자 프로필을 서버 트랜잭션에서 함께 만든다. 운영 Firestore 규칙에서는 이 예약 컬렉션을 클라이언트가 직접 쓰지 못하게 하고, 프로필의 닉네임 생성·변경도 서버를 통해서만 허용해야 한다. 기존 프로필 업데이트에 필요한 다른 필드 권한은 유지한다.
- 스파이방은 처음 다시 열 때 기존 방 문서의 메시지를 하위 컬렉션으로 옮긴다. 그 뒤의 메시지는 계속 보존하고 이전 기록은 페이지 단위로 제공한다. 이미 이전 버전에서 삭제된 기록은 복구하지 않는다.
